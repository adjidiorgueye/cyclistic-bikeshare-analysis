# Données

Les 12 fichiers CSV mensuels (octobre 2025 à septembre 2026) ne sont pas inclus dans ce dépôt, à cause de leur taille.

Source : données publiques de trajets Divvy, fournies par Motivate International Inc. sous licence d'utilisation publique, présentées comme données de l'entreprise fictive Cyclistic dans l'étude de cas Google Data Analytics Capstone (Case Study 1).

Lien de téléchargement :https://divvy-tripdata.s3.amazonaws.com/index.html

Colonnes : ride_id, rideable_type, started_at, ended_at, start_station_name, start_station_id, end_station_name, end_station_id, start_lat, start_lng, end_lat, end_lng, member_casual.
